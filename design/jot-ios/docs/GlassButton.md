Glass circle button for chrome actions (back, close, pause, copy) — translucent fill, 0.5px hairline, backdrop blur.

```jsx
<GlassButton size={46} onClick={back}><JotGlyph name="chevron-left" /></GlassButton>
```

For destructive transport buttons pass a red glyph: `<JotGlyph name="trash" color="var(--jot-red)" />`.
