# UI Kit — App Store Product Page

Fork of `appstore/` — Jot's App Store screenshot & preview rails:
iPhone 6.9″ (dark + light sets, 1290×2796) and Apple Watch (410×502).
Screens are built in HTML/CSS (`screens.css`) inside device frames (`frames.css`,
assembled by `frames.js`). Click any frame for a focus overlay.

These rails double as static recreations of core app screens (home/library,
live transcription, keyboard, Ask Jot, Watch) — useful as copy-paste sources.
Final raster exports live in `../../appstore/export/`.
