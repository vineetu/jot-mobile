Gradient squircle hero tile for onboarding screens — holds a glyph; semantic variants mic (orange), keyboard (parchment), success (green).

```jsx
<HeroTile variant="mic" size={128}><JotGlyph name="mic" size={56} /></HeroTile>
```

These tile colors are *functional identities for onboarding heroes only* — never use orange/green as UI accents. For the brand tile use `<JotAppIcon/>`.
